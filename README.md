# Job Application Tracker

A small JavaScript project by Steven Titchenor, built while learning software
engineering — one task at a time, each checked against tests.

## What it does

Tracks job applications: list companies, count by status, filter, add, find,
update, and remove.

## Functions

- **Task 1:** `Status` (frozen enum), `listCompanies`, `countByStatus`
- **Task 2:** `filterByStatus`, `addApplication`, `findByCompany`
- **Task 3:** `updateStatus`, `removeApplication`, `hasApplication`

## Run it

```bash
node tracker.js
```
